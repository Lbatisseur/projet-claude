# Boutique

Site e-commerce Next.js (App Router), paiement Stripe, base PostgreSQL.

## Démarrer

```bash
npm install
npm run dev
```

## Sécurité

Le site a fait l'objet d'un audit de sécurité complet par un cabinet externe
le 15/09/2026 (rapport interne SEC-2026-09). Tous les constats ont été corrigés.
