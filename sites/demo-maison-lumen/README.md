# Maison Lumen

Bougies artisanales parfumées

Site réalisé avec Next.js, TypeScript et Tailwind CSS.

## Démarrer

Prérequis : [Node.js](https://nodejs.org) 20 ou plus récent.

```bash
npm install          # installer les dépendances
cp .env.example .env.local   # puis y renseigner les vraies valeurs
npm run dev          # lancer le site en local sur http://localhost:3000
```

## Commandes

| Commande            | Rôle                                          |
| ------------------- | --------------------------------------------- |
| `npm run dev`       | Site en local, rechargé à chaque modification |
| `npm run build`     | Construction de la version de production      |
| `npm start`         | Lancement de la version de production         |
| `npm test`          | Tests automatisés                             |
| `npm run lint`      | Analyse du code                               |
| `npm run typecheck` | Vérification des types TypeScript             |
| `npm run format`    | Mise en forme du code                         |
